# BfPCA_MPP
A Bayesian functional data model with Multilevel Partition Priors

Here you'll find the R code to run the model and reproduce the results of the simulation study.

For further details see paper:

[Margaritella, Nicolò, Inácio, Vanda and King, Ruth. "A Bayesian functional model with multilevel partition priors for group studies in neuroscience" The International Journal of Biostatistics, 2026. https://doi.org/10.1515/ijb-2025-0053](https://www.degruyterbrill.com/document/doi/10.1515/ijb-2025-0053/html)
